# Campus Activity Manager

## Problem Statement

Managing student participation in campus events involves maintaining student records, event details, registrations, and participation information. When these activities are handled separately, it can become difficult to maintain organized records and apply basic rules such as preventing duplicate registrations and exceeding event capacity.

Campus Activity Manager provides a single command-line Java application for managing these activities in an organized manner.

## Scope of the Project

The project covers the management of students, campus events, event registrations, and participation records.

The current version provides a command-line interface and stores data in memory using Java collections. It supports operations such as adding, viewing, searching, updating, removing, registering, cancelling registrations, and recording participation.

The current version does not include persistent database storage, user authentication, networking, or a graphical interface.

## Target Users

The intended users of the system are:

- College administrators
- Faculty or staff managing campus activities
- Users responsible for maintaining event and participation records

## High-Level Features

- Student management
- Event management
- Event category management
- Student registration for events
- Duplicate registration prevention
- Event capacity validation
- Registration management
- Participation management
- Participation status updates
- Search and update operations
- Command-line based interaction
- Input validation and exception handling
